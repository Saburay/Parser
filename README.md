Кнопка "Открыть папку с данными":

Пользователь выбирает папку, где хранятся спарсенные данные.

Папка открывается в проводнике (Windows) или Finder (macOS).

Кнопка "Сохранить данные":

Пользователь выбирает путь для сохранения данных (например, конфигурации или логов).

Данные сохраняются в выбранном месте.

Как работает:
Открытие папки:

При нажатии на кнопку "Открыть папку с данными" открывается диалоговое окно для выбора папки.

После выбора папка открывается в системном проводнике.

Сохранение данных:

При нажатии на кнопку "Сохранить данные" открывается диалоговое окно для выбора пути и имени файла.

Данные сохраняются в выбранном месте.
